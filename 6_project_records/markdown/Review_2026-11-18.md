## Submission-ready standard (applies to all work from now on)

A piece of work counts as submission-ready only when every item below holds.

1. **Evidence first.** Every factual claim is backed by a file, an output or a citation. Nothing is described as done until it has been done and checked. Anything planned is labelled as planned.
2. **Traceable.** Every result points to a research question, objective and requirement, and to a specific location in the artefact (notebook cell, script line or Power BI page).
3. **Runnable by a marker.** The artefact opens and runs from the submitted link, uses relative paths and has a README with run steps.
4. **Referenced.** UWE Harvard style; every in-text citation appears in the reference list and every listed source is cited; DOIs and links checked.
5. **Within the word budget.** Section counts are recorded and the body stays at or below 5,800 words.
6. **Consistent.** Numbers, names, requirement IDs and chapter numbers agree across the text, figures, register and dashboard.
7. **Clean presentation.** British spelling, no causal wording, figures legible at print size, captions in the document and not baked into images.
8. **Attributed.** Own code is commented. AI assistance is disclosed as UWE requires. Third-party sources are credited.
